# 14 — Platform alignment recommendations

Research date: **16 November 2026**. Evidence detail and source URLs are in 10 (clearance), 11 (custody), 12 (prisons), 13 (data/hosting/procurement) and in 08 (rows added 16 Nov 2026). Status key as in 01. "Confirm with stakeholders" means no default value is evidenced and none should be shipped as if it were Ghanaian practice.

Current-behaviour references are to `packages/database/prisma/schema.prisma`, `apps/api/src/police/bgcheck.controller.ts` (`CERTIFICATE_VALIDITY_DAYS` default 180; convictions-only disclosure) and `apps/api/src/police/custody.controller.ts` (`CUSTODY_COURT_DEADLINE_HOURS` default 48). This file recommends; it changes no code.

Source short keys: **ES** = eservices.police.gov.gh public client bundle (16 Nov 2026); **MFA-LON / MFA-WAS** = london/washington.mfa.gov.gh police-clearance pages; **ACT30** = Act 30 consolidated to 2003 (WIPO Lex); **JTI** = Judicial Training Institute *Juvenile Justice Bench Book* (2011); **CHRAJ-06 / CHRAJ-21** = CHRAJ prison monitoring reports (2005–06; 2021); **A843** = Data Protection Act PDF from dpc.gov.gh; **A663** = Public Procurement Act 2003 PDF from ppa.gov.gh; **AGB** = *Agbemava v A-G* [2018] GHASC 95/52 excerpts quoting NRCD 46 s.34; press keys as in 10–13.

## 4. Things the evidence says **not** to change

| Principle | Why it holds |
|---|---|
| The system never computes release dates or decides remission | NRCD 46 s.34 makes remission "earned" and forfeitable; Art. 14(6) pre-trial credit is a court decision |
| No automatic release on warrant expiry | Release needs a court document (s.98 order, Form 25) or end-of-sentence decision; CHRAJ shows expired warrants are chased, not treated as releases |
| Convictions-only disclosure on clearances | Consistent with certificate wording, CDSB convict records and Act 30 s.108(2); widen only on written CID/CDSB instruction |
| NEXCUST does not replace the eServices clearance portal or CDSB | Both are live official systems (05; 10) |
| Synthetic data only | No DPC registration, processor contract or DPIA exists for NEXCUST (13) |
